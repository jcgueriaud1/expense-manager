# ADR-0014 — Java 25 in pom and Dockerfile

**Status:** Accepted

## Context
The generated skeleton is inconsistent: `pom.xml` sets `java.version=25` but the
`Dockerfile` builds and runs on Temurin **21**. That mismatch produces
"works locally, breaks in the container" surprises. Vaadin 25 requires Java 21+.

## Decision
Standardize on **Java 25** across the board: keep `pom.xml` at 25 and **update
the Dockerfile base images (build + runtime) to Temurin 25** so pom, dev, and
container agree.

## Consequences
- Build/dev/prod all agree on the JDK.
- The original 21/25 skeleton mismatch is logged as a Tooling/Template finding
  against start.vaadin.com.
- Verify a Temurin 25 JRE base image variant exists for the runtime stage
  (fall back to a non-alpine tag if the alpine variant is unavailable).
